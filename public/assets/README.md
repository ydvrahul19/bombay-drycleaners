# 📁 Bombay Drycleaners — Assets Folder

## How to use this folder

### 🖼️ Service Background Images
Place your custom photos in `/public/assets/services/` with these exact filenames:

| Filename | Service |
|---|---|
| `women-ethnic.jpg` | Designer Wear & Women's Ethnic |
| `saree-silk.jpg` | Saree & Silk Care |
| `sherwanis-mens.jpg` | Sherwanis & Men's Formal |
| `everyday-garments.jpg` | Everyday Garments |
| `curtains-drapes.jpg` | Curtains & Drapes |
| `sofa-cushions.jpg` | Sofa Covers & Cushions |
| `carpet-rug.jpg` | Carpet & Rug Cleaning |
| `misc-services.jpg` | Miscellaneous Services |

### 🌅 Hero Slideshow Images
Place your hero/banner photos in `/public/assets/hero/` with these filenames:

| Filename | Slide |
|---|---|
| `hero-1.jpg` | Slide 1 |
| `hero-2.jpg` | Slide 2 |
| `hero-3.jpg` | Slide 3 |
| `hero-4.jpg` | Slide 4 |
| `hero-5.jpg` | Slide 5 |

### 🏷️ Logo
- Logo file: `/public/assets/logo.png` (already set)

> **Tip:** For best results use JPG/PNG images at least 800×600px for service cards and 1400×800px for hero slides.
> If a custom image is not found, the website will automatically use a high-quality placeholder from Unsplash.
