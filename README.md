# Bombay Drycleaners Website

## 🚀 Deploy to Vercel (Step-by-Step)

### Prerequisites
- Node.js v20 or v22 installed
- Vercel account (free at vercel.com)

---

### Option A: Deploy via Vercel CLI (Command Line)

1. Open Command Prompt / Terminal **as Administrator**

2. Navigate to this folder:
   ```
   cd C:\path\to\bombay-drycleaners
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Login to Vercel:
   ```
   npx vercel login
   ```

5. Deploy:
   ```
   npx vercel --prod
   ```

6. Your site will be live at a URL like:
   `https://bombay-drycleaners.vercel.app`

---

### Option B: Deploy via GitHub + Vercel (Recommended for auto-updates)

1. Create a free GitHub account at github.com

2. Create a new repository called `bombay-drycleaners`

3. Upload all these files to GitHub

4. Go to vercel.com → New Project → Import from GitHub

5. Select your repo → Click Deploy

6. Done! Every time you update files on GitHub, your site auto-updates.

---

### Option C: Deploy via Netlify (Alternative)

1. Go to netlify.com → Sign up free
2. Drag and drop the entire `bombay-drycleaners` folder
3. Run `npm run build` first, then drag the `build` folder to Netlify
